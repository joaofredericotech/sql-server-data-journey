# SQL Server Data Journey

Meu portfólio de estudos e projetos na área de dados, com foco em SQL Server, consultas SQL e análise de dados.

## Objetivos
- Desenvolver conhecimentos em SQL e bancos de dados relacionais.
- Praticar consultas, filtros, JOINs e agregações.
- Construir projetos práticos para solucionar problemas usando dados.

## Tecnologias
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## Estrutura do repositório
- `01-fundamentos-sql/`: exercícios de fundamentos de SQL.
- `02-consultas-avancadas/`: consultas e técnicas avançadas.
- `03-projetos/`: projetos práticos de análise de dados.

Este repositório será atualizado conforme minha evolução e a conclusão de novos exercícios e projetos.
